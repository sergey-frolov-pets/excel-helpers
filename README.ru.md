# excel-helpers (ru/[`en`](https://github.com/sergey-frolov-pets/excel-helpers/README.md))
**_Инструменты Excel и VBA-макросы для решения конкретных бизнес-задач._**


- Подробности см. в [`Инструкции`](https://github.com/sergey-frolov-pets/excel-helpers/wiki).  
- [`Скачать`](https://github.com/sergey-frolov-pets/excel-helpers/releases/latest/download/excel-helpers.zip) последнюю версию.  
- Создать [`Новое сообщение`](https://github.com/sergey-frolov-pets/excel-helpers/issues/new/choose), чтобы поделиться новыми идеями, сообщить об ошибке и т.д.



**_Как использовать:_**
1. [`Скачайте`](https://github.com/sergey-frolov-pets/excel-helpers/releases/latest/download/excel-helpers.zip) Zip-файл с последней версией.<br>
1. Распакуйте Zip-файл в любую папку по вашему желанию.<br>
1. Откройте папку с нужным вам инструментом и откройте Excel-файл инструмента.<br>
1. Прочитайте руководство пользователя на листе «HowTo».<br>
1. Начните использовать инструмент.<br>
